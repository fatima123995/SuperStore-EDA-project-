# Superstore Sales Analysis

This repository contains an **exploratory data analysis (EDA)** of the Superstore dataset using Python and libraries. The project focuses on cleaning the data, analyzing sales trends, and visualizing key insights with charts to understand business performance.

## **Dataset**
The dataset includes the following columns:

- `Order ID`, `Order Date`, `Ship Date`, `Ship Mode`, `Customer Name`, `Segment`, `State`, `Country`, `Market`, `Region`, `Product ID`, `Category`, `Sub-Category`, `Product Name`, `Sales`, `Quantity`, `Discount`, `Profit`, `Shipping Cost`, `Order Priority`, `Year`

## **Project Steps**

### 1. Data Cleaning
- Converted `order_date` and `ship_date` columns to datetime  
- Checked for missing values and duplicates  
- Converted numeric columns to proper types  

### 2. Exploratory Data Analysis
- Analyzed **total sales by category, sub-category, and region**  
- Identified **Top 10 products by sales**  
- Time series analysis for **monthly and yearly sales trends**  
- Examined **profitability and discount patterns**  

### 3. Data Visualization
- **Clustered Bar Charts** for sub-category sales  
- **Pie Charts** for category sales distribution  
- **Category by Region charts** for geographical insights  

### 4. Key Insights
- Highlighted **best-selling products and categories**  
- Identified **high-profit regions**  
- Observed **seasonal sales trends**  


## **Tools Used**
- Python  
- Pandas
